# SkillBridge

SkillBridge is a mini freelance marketplace web application inspired by Fiverr.

The platform allows clients to post jobs and freelancers to submit proposals, communicate, and receive reviews.

---

# Features

- User authentication
- User profiles
- Job posting system
- Proposal submission
- Messaging system
- Review & rating system

---

# Tech Stack

## Frontend
- React
- TailwindCSS
- React Router
- Axios

## Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
